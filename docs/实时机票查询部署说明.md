# 实时机票查询部署说明

两个页面固定查询上海浦东（PVG）往返曼谷素万那普（BKK）：2027 年 2 月 10 日去程、2 月 18 日返程、经济舱、1 名成人。春秋航空页仅保留 9C，泰国航空页仅保留 TG；服务端会再次验证去返程均为直飞，按人民币含税往返价升序返回。

## 一次性配置

1. 在 [Ignav](https://ignav.com/) 注册免费账户并创建 API key。免费账户有每月调用额度；不要把 key 发到群聊、提交到 Git，或写入网页源码。
2. 打开 Cloudflare Dashboard → Pages → `family-trip-2026` → Settings → Variables and Secrets，新增加密变量：

   - 名称：`IGNAV_API_KEY`
   - 值：刚创建的 API key
   - 环境：Production（如希望预览环境也能查询，同时添加 Preview）

3. 首次部署前执行一次生产 D1 数据库迁移，以创建查询记录表：

   ```powershell
   npx wrangler d1 execute family-trip-comments --remote --file migrations/0001_flight_price_queries.sql
   ```

4. 部署网站。页面打开或点击“重新查询”时才消耗一次免费 API 调用；每次成功查询会写入 D1 的 `flight_price_queries` 表。

## 运行边界

- 价格来自航班数据服务，且会随库存变化；付款前仍需在航司官网核实。
- 没有可售的直飞指定航司航班时，页面会明确显示无结果，不会用旧价格替代。
- 当前固定为单人价格，方便横向比较；实际家庭团购票时请在航司页面按乘客人数重新确认总价和行李额度。
